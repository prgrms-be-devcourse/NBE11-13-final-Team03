# 검토된 인벤토리

`baseline-2026-10-28.json`은 운영자가 제공한 내보내기에서 필요한 식별자·속성만 추린 기준본이다.
원본 파일 해시를 기록하며, 실시간 운영 상태나 권한·배포 검증 결과로 취급하지 않는다.
`unknowns`는 해당 조회 범위의 후속 기준본과 담당자 확인으로 해소한다.

`network-2026-10-28.json`은 network 범위 재조회(`complete=true`)에서 네트워크 import에 필요한 속성만 정리한 기준본이다.
VPC·서브넷·IGW·라우팅/연결·보안 그룹/규칙 ID와 원본 SHA256을 포함한다.
VPC DNS 속성은 미수집으로 남겼으며 IAM·CloudFront 등 다른 범위의 기존 미확인 항목까지 해소한 것은 아니다.

원본 출력은 `raw/` 또는 저장소 밖의 비공개 폴더에 보관한다. `.gitignore`가 모든 임의 경로의 원본을 막는 것은 아니므로 stage 목록을 검토한다.
원본 정책·Function 코드·origin 사용자 지정 헤더·계정 내 다른 자원 정보는 통째로 커밋하지 않는다.
추가 기준본에도 관측 일시·출처와 미확인 항목을 구분해 남긴다.

전체 import의 운영 입력은 `--scope import`로 실행 시 수집하고 저장소 밖의 private tfvars로 변환한다.
실제 IAM 정책·origin 헤더·Function 소스는 합성 테스트 자료와 구분하며 커밋하지 않는다.
